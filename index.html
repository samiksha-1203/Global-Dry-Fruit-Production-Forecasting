Negative differences favor the tuned model. If the confidence interval crosses the zero line, it includes no difference; here, it crosses zero, consistent with the test not establishing superiority.

The paired comparison uses country-item series-clustered standard errors to account for repeated yearly observations within a series. It assumes different country-item series are independent, which may not fully hold because global shocks can affect multiple series. Interpret this as evidence from one temporal holdout, not proof of universal model superiority.

Model-family selection and hyperparameter tuning use chronological folds drawn only from training targets through 2021. The 2022–2024 holdout is reserved for final evaluation. Test predictions use observed lag inputs for each test year (rolling one-year-ahead evaluation), not recursive multi-year forecasts. MAPE is sensitive to small actual values; compare it with MAE, RMSE, and WAPE. These results are retrospective on this dataset, not external validation on new countries, crops, or future years.

How this dashboard is built

01 · FAOSTAT dataRaw country, crop, year, area, yield, and production records.
02 · Python analysisCleaning, exploratory plots, lag feature creation, and chronological train/test split.
03 · Model trainingRandom Forest and XGBoost are compared with a previous-year baseline; the selected model is tuned and refit.
04 · HTML dashboardThe pipeline exports dashboard data; this page renders charts, metrics, and the forecast selector.
Source: FAOSTAT Crops and livestock products (QCL). Historical data and model forecasts are distinct; forecast values are not official observed production.
