# Dry Fruits Around the World

A simple, data-driven project that turns FAOSTAT crop records into a clean forecasting story for dry-fruit production worldwide.

This repository brings together raw agricultural data, a Python analysis pipeline, model-ready datasets, charts, and an interactive dashboard that helps explore how production changes across countries and crops.

## What this project does

The project predicts the next year's production in tonnes for each country and selected crop item, such as almond output in a given country. It uses recent production, harvested area, and yield values, along with country and crop labels, to build one-year-ahead forecast estimates.

The current output is for 2025, based on historical data through 2024. Forecasts are included only where enough recent data exists to support a credible estimate.

This is a crop-production forecasting project, not a model for prices, consumption, exports, or nutritional value. The source data is based on FAOSTAT crop categories such as nuts, dates, and figs, which makes it a good proxy for a dry-fruit and nut topic without covering every processed dried product.

## Data source and scope

The pipeline starts from [`data/raw/DRY FRUIT COUNTRY WISE.csv`](./data/raw/DRY%20FRUIT%20COUNTRY%20WISE.csv), a FAOSTAT export with records covering area, item, year, production, area harvested, yield, and related metadata.

The script cleans the data, removes unusable rows, standardizes selected country names, filters to the nine relevant crop categories, and builds a consistent country-item-year dataset. It keeps production rows even when they are zero, removes duplicate keys, and calculates yield only when it can be derived reliably.

### Cleaned dataset fields

| Column | Meaning | Unit |
| --- | --- | --- |
| `Country` | Country or area name | — |
| `Dry_Fruit` | Selected crop item | — |
| `Year` | Reporting year | calendar year |
| `Area_Harvested` | Harvested area | hectares |
| `Production` | Crop production | tonnes |
| `Yield` | Reported or calculated yield | kg/ha |

## Model workflow

The main analysis script performs the full pipeline:

1. Load and inspect raw FAOSTAT records
2. Clean, filter, and reshape the data
3. Explore production trends and relationships
4. Create lag features using previous 1-, 2-, and 3-year values
5. Compare model families and select the best one
6. Tune the chosen model using training-period folds
7. Evaluate on a held-out period
8. Refit the final model and generate 2025 forecasts
9. Export dashboard-ready outputs and charts

### Model inputs and target

- Target: production in tonnes for the prediction year
- Categorical features: country and crop item
- Numeric features: lagged production, harvested area, and yield for the prior years
- Evaluation setup: training-period model choice and tuning are done before the final holdout period is used for evaluation

### Model comparison and reporting

The workflow compares Random Forest and XGBoost against a previous-year baseline. Model selection is based on pooled MAE across chronological validation folds, while final performance is measured on the held-out 2022-2024 period using metrics such as MAE, RMSE, R-squared, MAPE, and WAPE.

The project also includes a statistical comparison and trend test to show whether gains are meaningful and whether the broader production series has a positive trend over time.

## Dashboard

The dashboard is a static, browser-based experience generated from the analysis pipeline. It includes:

- a world map of production by country and crop
- year and crop filters
- headline KPI cards
- forecast selectors
- trend and ranking charts
- model comparison visuals
- chart gallery with the generated figures

It reads `outputs/dashboard_data.js` and loads Plotly from a CDN, so it works best when the project stays together and internet access is available.

## Run locally

### View the dashboard

Open a terminal in the project folder and run:

```powershell
python -m http.server 8000
```

Then open: `http://localhost:8000`

### Run the Python workflow

```powershell
$env:PYTHONIOENCODING = "utf-8"
python -m pip install -r requirements.txt
python dry_fruits_production_analysis.py
```

This reads the raw FAOSTAT CSV and writes refreshed outputs into the `outputs/` folder.

## GitHub Pages

Because the dashboard is static, it can be published with GitHub Pages.

1. Create a public GitHub repository.
2. Push the project files.
3. Open GitHub repository settings and enable Pages.
4. Select the `main` branch and the root folder.
5. Publish and open the generated site URL.

This project is designed to be easy to share, explore, and reproduce.

### Important note

The FAOSTAT categories used here are crop categories rather than every processed dried-fruit product. For example, dates and figs are included because they are crop items in the source dataset, while raisins, prunes, and other processed products are not represented here.

This project is best understood as a practical, transparent dry-fruit production analysis built on public agricultural data.
